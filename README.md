# Koko Cafe Room

Responsive premium black-and-gold digital menu.

## Run locally
Open this folder in VS Code, then open `index.html` with Live Server.

## Files
- `index.html` — page structure
- `style.css` — visual design and responsive layout
- `script.js` — menu data, categories, search, language switch

## Before publishing
1. Confirm every product name and price with the cafe manager.
2. Confirm the phone number format and address label.
3. Replace stock food photos with cafe-approved photos if available.
4. Test all image links, mobile layout, map and phone links.
5. Publish using GitHub Pages. QR code should point to the final public site URL.
